# Wardogs Artillery – Stream Deck Plugin

> Stream Deck Plugin zur schnellen und präzisen Berechnung von Mörser- und Artillerie-Werten direkt über das Elgato Stream Deck.

---

## 🎯 Übersicht

Das **Wardogs Artillery Plugin** (`de.wardogs.artillery.sdPlugin`) wurde entwickelt, um Artillerie- und Mörserdaten (Distanz, Elevation, Azimut/Winkel) ohne zeitraubendes Tabben oder externe Rechner direkt auf den Tasten des Stream Decks abzurufen und einzustellen.

- **Plugin-ID:** `de.wardogs.artillery.sdPlugin`
- **Entwickler / Clan:** Wardogs
- **Plattform:** Windows 11 / Stream Deck Software ab v6.x

---

## ✨ Features

- **Schnelle Zielwert-Berechnung:** Direkte Umrechnung von Koordinaten / Distanzen in Höhenwinkel (Elevation) und Richtkreis.
- **Tasten-Feedback:** Übersichtliche Anzeige der Werte direkt auf den Tasten-Displays.
- **Preset-Unterstützung:** Schneller Wechsel zwischen verschiedenen Munitionstypen oder Ladungsstufen (Charges).
- **Kein Tabben nötig:** Das Spiel bleibt voll im Fokus, alle Werte lassen sich per Tastendruck durchschalten oder anpassen.

---
